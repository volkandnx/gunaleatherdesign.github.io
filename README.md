# 👜 GunaLeather Design

**Guna Leather Design**, geleneksel el işçiliğini modern estetikle buluşturan, premium deri ürünleri odaklı bir vitrin web sitesidir. Günal ailesinin zanaatkarlık mirasını dijital dünyaya taşımayı hedefler.

## 🚀 Proje Hakkında
Bu web sitesi, yüksek kaliteli deri çantalar, cüzdanlar ve aksesuarlar için minimalist ve lüks bir sergileme alanı sunar. "Sessiz lüks" (Quiet Luxury) tasarım anlayışıyla kurgulanmış olup, doğrudan satış yerine potansiyel müşterileri WhatsApp üzerinden iletişime yönlendirmek üzere tasarlanmıştır.

## ✨ Öne Çıkan Özellikler
- **Minimalist Tasarım:** Deri dokusunu ön plana çıkaran, yüksek kontrastlı ve karanlık tema (Dark Mode) estetiği.
- **WhatsApp Entegrasyonu:** Müşterilerin tek tıkla ürünler hakkında bilgi almasını sağlayan otonom mesaj yönlendirmesi.
- **Hızlı ve Statik Yapı:** GitHub Pages üzerinden sunulan, düşük gecikmeli ve yüksek performanslı sayfa yapısı.
- **Responsive Arayüz:** Hem masaüstü hem de mobil cihazlarda sorunsuz kullanıcı deneyimi.
